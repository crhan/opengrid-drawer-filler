# 库存感知评分系统 - 成本计算逻辑

基于需要打印的 opengrid 来进行成本计算

1. 以总打印时间作为成本进行考量，以分钟作为单位来计算
2. 以最终需要打印的 opengrid 进行计算
3. 每批次打印作为一个独立的计算单元
4. 批次内的每个 stack 计算方式你要自己生成，但是后面我会给你一些数据样例
5. 每有一个新增的批次，在批次间都需要增加罚时 60 分钟
