# 库存感知评分系统 v2 设计文档

## 重点内容

**必须第一优先级处理，不能冲突**

- 你要做的是测试代码的实现，你要忠实的还原测试意图，而不是通过修改测试代码来让测试通过
- 你绝对不能通过调用内部函数来测试
- 这个测试文档描述的是 cli 端到端测试，你应该模拟用户的操作来重现测试场景，遵循以下步骤：
  a. 创建临时目录
  b. 生成 config 和 inventory（只做一次，后续复用）
  c. 调用 scripts/opengrid.py 脚本进行测试（多次调用）
  d. 通过脚本输出来确认测试目的达成

## 全局验证要求

所有涉及方案调整的场景（重新规划、批量优化等）都需要验证：

**格子数量一致性：** 拆分/调整前后的瓦片总格子数必须保持一致。

- 例如：原始方案 [(6,9), (6,9)] 总格子数为 6×9×2 = 108 格
- 调整后方案总格子数也必须为 108 格

## 场景 1：精确匹配

**验证意图：** 验证"有库存一定要用库存"的核心要求

**假设：**

- 抽屉：265×360（9×12格子 = 108格）
- 库存：6×9 有 2 个（6×9×2 = 108格，可完全覆盖）

**预期结果：**

- 完全使用库存，无需打印
- 打印时间 = 0

**验证目标：**

```
[ ] 打印时间 = 0
[ ] from_inventory = {'6x9': 2}
[ ] need_print = {}
[ ] 库存使用不超过提供数量
```


## 场景 4c：批量模式（库存3个）- 全局优化

**验证意图：** 验证库存3个时，抽屉2也能通过重新规划使用库存

**假设：**

- 抽屉 1：265×360，需要2个6×9
- 抽屉 2：325×365，可重新规划使用6×9
- 库存：6×9 有 **3 个**

**关键洞察：**

- 抽屉1需要2个6×9
- 抽屉2的原始方案 [(5,6), (5,7), (6,6), (6,7)] 不包含6×9
- 但抽屉2可以重新规划，使用6×9替代部分瓦片

**预期结果：**

- 抽屉1：使用2个库存，无需打印
- 抽屉2：使用1个库存 + 打印剩余
- 剩余0个库存

**验证目标：**

```
[ ] 抽屉1无需打印
[ ] 抽屉2使用1个库存
[ ] 库存刚好用完
```

## 场景 4d：批量模式（库存4个）- 全局优化

**验证意图：** 验证库存4个时的全局优化（抽屉2只能用1个库存）

**假设：**

- 抽屉 1：265×360，需要2个6×9
- 抽屉 2：325×365，11×13格子最多只能包含1个6×9
- 库存：6×9 有 **4 个**

**关键洞察：**

- 11×13格子无法包含2个6×9（6+6=12>11 或 9+9=18>13）
- 只能包含1个6×9
- 1×6 是非法尺寸（最小2×2）

**预期结果：**

- 抽屉1：使用2个库存，无需打印
- 抽屉2：使用1个库存 + 打印剩余
- 库存剩余1个

**验证目标：**

```
[ ] 抽屉1无需打印
[ ] 抽屉2使用至少1个库存
[ ] 库存使用不超过提供数量
```

## 场景 5：重新规划（边缘情况）

**验证意图：** 验证当库存尺寸不能精确匹配时，会重新规划方案，使用部分库存后仍需打印

**假设：**

- 抽屉：265×360 (9×12格子)，原始方案需要 2 个 6×9
- 库存：6×6 有 2 个

**关键洞察：**

- 抽屉原始方案是 2 个 6×9 瓦片（总面积 108 格）
- 6×6 瓦片可以放入 9×12 的格子（6<9, 6<12）
- 用 6×6 替代部分 6×9 后，剩余空间需要打印补充

**预期结果：**

- 使用 2 个 6×6 库存
- 打印时间降低（> 0，因为仍需打印剩余部分）

**验证目标：**

```
[ ] 方案包含 6x6 瓦片（使用库存）
[ ] 仍有需要打印的瓦片
[ ] 打印时间 < 无库存时的打印时间
[ ] 库存使用不超过提供数量
[ ] 格子数量一致（拆分前后总格子数不变）
```

## 场景 7a：3抽屉 + 重新规划（库存 3 个）

## 场景 7b：3抽屉 + 重新规划（库存 5 个）— 最复杂场景

**验证意图：** 验证3个抽屉时库存有余，抽屉3需要重新规划

**假设：**

- 抽屉 1：265×360 → [(6,9), (6,9)] - 需要 2个6×6
- 抽屉 2：325×365 → [(6,7), (6,6), (5,7), (5,6)] - 需要 1个6×6
- 抽屉 3：420×392 → [(5,7)×6] - 6×6 可放入（36>35），可重新规划
- 库存：6×6 有 **5 个**

**关键洞察：**

- 抽屉1和2只需3个库存
- 抽屉3原方案 [(5,7)×6] 无法直接使用 6×6
- 但可以重新规划使用 6×6
- 库存剩余 2 个，可以尝试给抽屉3重新规划

**预期结果：**

- 抽屉1：使用 2 个 6×6 + 打印剩余
- 抽屉2：使用 1 个 6×6 + 打印剩余
- 抽屉3：尝试重新规划（使用库存或不使用的最优方案）

**验证目标：**

```
[ ] 抽屉1仍需打印部分瓦片
[ ] 抽屉2仍需打印部分瓦片
[ ] 总打印时间最优（不因使用库存反而增加）
[ ] 库存使用不超过提供数量
[ ] 格子数量一致（拆分前后总格子数不变）
```

## 场景 8：6抽屉 + 双库存尺寸（8×8 和 6×7）

**验证意图：** 验证多个抽屉、多种库存尺寸的全局优化

**假设：**

- 抽屉1：265×360 × 2（格子 9×12）
- 抽屉2：325×360 × 2（格子 11×12）
- 抽屉3：315×360 × 2（格子 11×12）
- 库存：8×8 有 **5 个**，6×7 有 **5 个**

**关键洞察：**

- 6个抽屉需要批量优化
- 两种库存尺寸需要同时考虑
- 325和315抽屉相同尺寸，优化空间大

**预期结果：**

- 总打印时间 < 无库存时的总打印时间
- 8×8 和 6×7 库存使用都不超过提供量
- 每个抽屉都有需要打印的瓦片

**验证目标：**

```
[ ] 总打印时间 < 无库存时的总打印时间
[ ] 8x8库存不超限
[ ] 6x7库存不超限
[ ] 所有抽屉都有需要打印的瓦片
```
