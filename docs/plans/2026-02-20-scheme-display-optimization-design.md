# 方案展示优化设计

**Date**: 2026-02-20
**Status**: Approved (更新)

## 背景

优化方案展示的信息量和可读性，帮助用户在多个方案中做出更好的选择。

## 决策

1. **可视化布局**: 风格 2 - 带尺寸标注
2. **详细统计**: 终端和 HTML 都显示完整统计
3. **对比表格**: 两种方案时显示对比表格
4. **自动双方案**: 有库存时自动计算并对比两种方案

---

## 新增：自动双方案对比

### 问题

用户在有库存的情况下，默认只看到"使用库存"的方案。如果想对比"不使用库存"的方案，需要手动指定参数，交互不流畅。

### 解决方案

当检测到有库存时，自动计算两种方案：
- 方案 A：不考虑库存（最优打印次数）
- 方案 B：使用库存

### 展示内容

#### 1. 库存覆盖率分析

| 瓦片尺寸 | 库存数量 | 需要数量 | 状态 |
|---------|---------|---------|------|
| 8×8 | 9 块 | 4 块 | ✅ 充足 |
| 6×7 | 5 块 | 2 块 | ✅ 充足 |
| 8×4 | 0 块 | 4 块 | ❌ 需要打印 |

覆盖率: X/Y 种尺寸被覆盖 (Z%)

#### 2. 方案对比表格

| 项目 | 方案 A (无库存) | 方案 B (用库存) |
|------|-----------------|-----------------|
| 打印次数 | 2 | 6 |
| 耗材 | 885g | 481g |
| 时间 | 38h | 21h |
| 库存使用 | ❌ | ✅ 6 stack |

#### 3. 用户选择提示

```
[ A ] 方案 A - 不考虑库存 (2次打印, 38h, 885g)
[ B ] 方案 B - 使用库存 (6次打印, 21h, 481g, 节省库存)
[ G ] 生成 STL 文件（默认方案 B）
[ Q ] 退出
```

## 原设计（保持不变）

### 1. 可视化布局

采用风格 2：带尺寸标注

```
┌───────────┬─────────┐
│   7×5     │   3×5   │
│ ┌───────┐ │ ┌─────┐ │
│ │       │ │ │     │ │
│ └───────┘ │ └─────┘ │
├───────────┼─────────┤
│   7×5     │   3×5   │
│ ┌───────┐ │ ┌─────┐ │
│ │       │ │ │     │ │
│ └───────┘ │ └─────┘ │
└───────────┴─────────┘
```

HTML 可视化：使用不同颜色区分瓦片尺寸，显示尺寸标注

### 2. 详细统计

每个方案显示：
- 抽屉尺寸和份数
- 分割方案（每种尺寸的数量）
- 瓦片数量（stack）
- 打印时间
- 预估耗材（g）
- 库存使用情况（如果有）
- 节省百分比（如果使用库存）

### 3. 对比表格

当展示两种方案时显示：

| 项目 | 方案 A | 方案 B |
|------|--------|--------|
| 分割 | 7×5×2 + 3×5×2 | 7×5×2 + 3×5×2 |
| 需打印 | 4 stack | 2 stack |
| 打印时间 | 12.4 min | 6.2 min |
| 耗材 | 45.2g | 22.6g |

### 4. 用户引导

```
请选择方案：
[ A ] 方案 A - 标准分割
[ B ] 方案 B - 使用库存（节省 50%）
[ Q ] 退出
```
