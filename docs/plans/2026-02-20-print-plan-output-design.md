# openGrid 打印计划输出改进设计

## 背景

用户反馈当前的打印计划输出中，"来源"列不够清晰，难以快速理解每个瓦片来自哪个抽屉。

## 目标

改进批量计算输出的可读性，通过为每个打印目标分配唯一名称，使来源指代清晰。

## 自动命名规则

- **唯一尺寸**：直接用尺寸命名，如 `265×360`
- **重复尺寸**：自动加序号，如 `265×360#1`, `265×360#2`

示例：
- 输入: `265x360:2 325x360:2 315x360:2`
- 生成名称:
  - `265×360#1` (265×360mm, 1份)
  - `265×360#2` (265×360mm, 1份)
  - `325×360#1` (325×360mm, 1份)
  - `325×360#2` (325×360mm, 1份)
  - `315×360#1` (315×360mm, 1份)
  - `315×360#2` (315×360mm, 1份)

## 输出格式设计

### 1. 打印目标对照表（新增）

```
======================================================================
--- 打印目标 ---
======================================================================

| 名字 | 尺寸 | 份数 |
|------|------|------|
| 265×360#1 | 265×360mm | 1 |
| 265×360#2 | 265×360mm | 1 |
| 325×360#1 | 325×360mm | 1 |
| 325×360#2 | 325×360mm | 1 |
| 315×360#1 | 315×360mm | 1 |
| 315×360#2 | 315×360mm | 1 |
```

### 2. 各尺寸分割方案（保留，使用名称）

```
265×360#1 × 1 份:
  格子: 9 × 12
  分割: 2×2
  ...
```

### 3. 合并后的瓦片清单（改进来源列）

```
8×8 格 (224mm × 224mm):
  来源: 325×360#1, 325×360#2, 315×360#1, 315×360#2
  库存: 4
  需打印: 无 (完全使用库存)

8×4 格 (224mm × 112mm):
  来源: 325×360#1, 325×360#2, 315×360#1, 315×360#2
  需打印: 4
  打印: 1次 (4 stack, 29mm)
    耗材: 152.3g, 时间: 6h36m
```

## 实现要点

1. **命名生成逻辑**：在 `batch_mode` 函数中，根据解析出的 items 生成唯一名称
2. **名称传递**：将名称映射传递到后续处理流程
3. **输出修改**：修改打印格式，用名称代替尺寸+份数

## 兼容性

- 不影响单尺寸计算模式
- 不影响 JSON 输出格式
- `-i ""` 禁用库存功能保持不变
