# openGrid Print Plan HTML Design

## Design Direction: Technical Industrial

A clean, precise interface inspired by CAD software and professional 3D printing tools. Dark theme with sharp accent colors.

### Visual Style
- **Background**: Deep charcoal (#0d0d0d) with subtle grid pattern
- **Cards**: Slightly lighter dark (#1a1a1a) with subtle border
- **Accent**: Vibrant orange (#ff6b35) for primary actions
- **Secondary**: Cyan (#00d4ff) for inventory items
- **Typography**:
  - Headings: "JetBrains Mono" for technical feel
  - Body: System monospace for data

### Page Sections
1. **Header**: Project name, date, status badge
2. **Info Cards**: Grid layout showing drawer dimensions, stats
3. **Assembly SVG**: Centered, with subtle glow effect
4. **Tile Grid**: Color-coded tiles (inventory vs print)
5. **File List**: STL files with open buttons
6. **Actions**: 3MF template button

### Animations
- Subtle fade-in on load
- Hover effects on interactive elements
- Smooth transitions
