# Batch 模式全局优化设计

## 目标

在 batch 模式下，不仅独立计算每个抽屉的最优方案，还要考虑跨抽屉的全局优化，选择能减少总打印次数的分割方案组合。

## 核心思路

```
步骤1：贪心初始解（现有逻辑）
  - 每个抽屉独立找最优方案

步骤2：局部搜索优化（新逻辑）
  - 对于每个抽屉，生成所有可行分割方案
  - 遍历所有方案组合，找打印次数最少的
  - 选择让总打印次数最少的那组方案
```

## 关键函数设计

### find_all_schemes(x, y)

生成某个抽屉的所有有效分割方案。

输入：网格尺寸 (x, y)
输出：所有有效方案列表
```python
[
    {'x_splits': [7, 10], 'y_splits': [5, 5, 5], 'tiles': [(7,5), (10,5), ...]},
    {'x_splits': [8, 9], 'y_splits': [5, 5, 5], 'tiles': [(8,5), (9,5), ...]},
    ...
]
```

### calculate_total_prints(batch_results, schemes)

给定每组方案，计算总打印次数。

1. 合并所有方案的瓦片
2. 统计每个瓦片尺寸的总 stacks
3. 计算每个尺寸需要的打印次数
4. 汇总返回总打印次数

### optimize_batch_global(batch_results)

贪心 + 局部搜索优化主函数。

```
1. 对每个抽屉调用 find_all_schemes
2. 各自找最优作为初始解
3. 遍历所有方案组合（可设上限避免组合爆炸）
4. 选打印次数最少的组合
```

## 优化策略

- **完全开放**：只要最终打印次数减少就采用，不限制方案变化
- **组合上限**：为避免组合爆炸，限制每个抽屉最多考虑前 N 个最优方案
- **缓存优化**：对相同瓦片集合的打印次数计算做缓存

## 测试用例设计

### test_fixed_drawer_sizes
验证固定抽屉尺寸下，是否找到所有方案中打印次数最少的。

### test_alternative_schemes
验证当某个抽屉有多种分割方案可选时，算法是否能选到导致更多共享的方案。

### test_fixed_tile_set
给定瓦片集合，验证打包算法正确计算打印次数。

### test_mixed_scenarios
混合场景测试：部分抽屉有多种方案，部分只有一种。

### test_performance_degradation
性能测试：验证大数据量下的执行时间在合理范围内。

## 预期效果

假设三个抽屉：
- 325×365 (2份)
- 315×365 (2份)
- 265×365 (2份)

优化前（独立最优）：各自找最优，合并后统计
优化后：尝试不同方案组合，选择打印次数最少的

目标：减少总打印次数或保持相同但瓦片共享更优。
