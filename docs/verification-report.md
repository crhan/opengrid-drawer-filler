# 库存感知评分系统 v2 验证报告

## 测试场景总览

| 场景 | 描述 | 核心验证点 |
|------|------|-----------|
| 1 | 精确匹配 | 成本 = 0 |
| 2 | 部分匹配 | 只计算差额 |
| 3 | 库存方案选择 | 算法优先选择库存方案 |
| 4 | 批量模式 | 全局优化 |
| 5 | 重新规划 | 非精确匹配处理 |
| 6a | 批量+重新规划(3个库存) | 库存刚好够用 |
| 6b | 批量+重新规划(5个库存) | 库存有余 |
| 7a | 3抽屉+重新规划(3个库存) | 3抽屉全局优化 |
| 7b | 3抽屉+重新规划(5个库存) | 库存重新规划优化 |

---

## 场景 1：精确匹配

**验证意图：** 验证"有库存一定要用库存"的核心要求

**假设：**
- 库存：6×7 有 2 个
- 需求：2 个 6×7 瓦片

**预期结果：**
- 成本 = 0（完全使用库存）
- 不产生任何打印

**验证目标：**
```
[ ] 成本 = 0
[ ] from_inventory = {'6x7': 2}
[ ] need_print = {}
```

---

## 场景 2：部分匹配

**验证意图：** 验证库存不足时只计算差额

**假设：**
- 库存：6×7 有 1 个
- 需求：2 个 6×7 瓦片

**预期结果：**
- 库存取 1 个，打印 1 个
- 成本 = 1 个瓦片的打印时间

**验证目标：**
```
[ ] from_inventory = {'6x7': 1}
[ ] need_print = {'6x7': 1}
[ ] 成本 > 0 但 < 无库存时的成本
```

---

## 场景 3：库存方案选择

**验证意图：** 验证算法会优先选择能使用库存的方案

**假设：**
- 抽屉：265×360（格子 9×12）
- 库存：6×6 有 5 个

**预期结果：**
- 选择能使用库存的方案（如 [(3,6), (3,6), (6,6), (6,6)]）
- 而不是原始最优的 [(6,9), (6,9)]

**验证目标：**
```
[ ] 方案包含 6x6
[ ] 成本 < 无库存方案的成本
```

---

## 场景 4：批量模式

**验证意图：** 验证批量模式下能考虑库存进行全局优化

**假设：**
- 抽屉 1：265×360，需要 6×9
- 抽屉 2：325×365，需要 6×11
- 库存：6×9 有 1 个

**预期结果：**
- 抽屉 1 使用库存（成本 0）
- 抽屉 2 正常打印

**验证目标：**
```
[ ] 抽屉1成本 = 0
[ ] 总成本降低
```

---

## 场景 5：重新规划（边缘情况5）

**验证意图：** 验证当库存尺寸不能精确匹配时，会重新规划方案

**假设：**
- 需求：6×9 两个
- 库存：6×6 有 3 个

**预期结果：**
- 使用 2 个 6×6 库存
- 成本显著降低

**验证目标：**
```
[ ] replan_with_inventory 返回非空结果
[ ] 成本 < 原方案成本
```

---

## 场景 6a：批量 + 重新规划（库存 3 个）

**验证意图：** 验证库存刚好够用时的全局优化

**假设：**
- 抽屉 1：265×360 → [(6,9), (6,9)] - 需要 2个6×6
- 抽屉 2：325×365 → [(6,7), (6,6), (5,7), (5,6)] - 需要 1个6×6
- 库存：6×6 有 **3 个**（正好够用）

**预期结果：**
- 抽屉1：使用 2 个 6×6 → 成本 = 0
- 抽屉2：使用 1 个 6×6 → 打印剩余

**验证目标：**
```
[ ] 抽屉1成本 = 0
[ ] 抽屉2成本 > 0
[ ] 总成本 < 分别打印的成本
```

---

## 场景 6b：批量 + 重新规划（库存 5 个）

**验证意图：** 验证库存有余时的处理

**假设：**
- 抽屉 1：265×360 → [(6,9), (6,9)] - 需要 2个6×6
- 抽屉 2：325×365 → [(6,7), (6,6), (5,7), (5,6)] - 需要 1个6×6
- 库存：6×6 有 **5 个**（多 2 个）

**预期结果：**
- 抽屉1：使用 2 个 6×6 → 成本 = 0
- 抽屉2：使用 1 个 6×6 → 打印剩余
- 剩余 2 个保留

**验证目标：**
```
[ ] 抽屉1成本 = 0
[ ] 总成本降低
[ ] 库存扣减正确（使用3个，剩余2个）
```

---

## 场景 7a：3抽屉 + 重新规划（库存 3 个）

**验证意图：** 验证3个抽屉时库存不够的全局优化

**假设：**
- 抽屉 1：265×360 → [(6,9), (6,9)] - 需要 2个6×6
- 抽屉 2：325×365 → [(6,7), (6,6), (5,7), (5,6)] - 需要 1个6×6
- 抽屉 3：420×392 → [(5,7)×6] - 需要 0个6×6（5<6，放不下）
- 库存：6×6 有 **3 个**

**预期结果：**
- 抽屉1：使用 2 个 6×6 → 成本 = 0
- 抽屉2：使用 1 个 6×6 → 打印剩余
- 抽屉3：不使用库存

**验证目标：**
```
[ ] 抽屉1成本 = 0
[ ] 总成本 < 分别打印的成本
[ ] 库存使用数量 = 3
```

---

## 场景 7b：3抽屉 + 重新规划（库存 5 个）— 最复杂场景

**验证意图：** 验证3个抽屉时库存有余，抽屉3需要重新规划

**假设：**
- 抽屉 1：265×360 → [(6,9), (6,9)] - 需要 2个6×6
- 抽屉 2：325×365 → [(6,7), (6,6), (5,7), (5,6)] - 需要 1个6×6
- 抽屉 3：420×392 → [(5,7)×6] - 6×6 可放入（36>35），可重新规划
- 库存：6×6 有 **5 个**

**关键洞察：**
- 抽屉1和2只需3个库存
- 抽屉3原方案 [(5,7)×6] 无法直接使用 6×6
- 但可以重新规划使用 6×6
- 库存剩余 2 个，可以尝试给抽屉3重新规划

**预期结果：**
- 抽屉1：使用 2 个 6×6 → 成本 = 0
- 抽屉2：使用 1 个 6×6 → 打印剩余
- 抽屉3：尝试重新规划（使用库存或不使用的最优方案）

**验证目标：**
```
[ ] 抽屉1成本 = 0
[ ] 抽屉2成本 > 0
[ ] 全局优化决策正确（库存给最需要的抽屉）
[ ] 总成本最优
```
