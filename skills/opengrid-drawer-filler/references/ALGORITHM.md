# 算法规则

## 核心参数（动态）

> **注意**: 以下常量值由 `opengrid_config.yaml` 配置决定，通过代码动态计算。

| 参数 | 来源 | 说明 |
|------|------|------|
| `TILE_SIZE` | 配置文件 | 网格单元格大小 (默认 28mm) |
| `MAX_X`, `MAX_Y` | 打印机 bed | 基于打印机 XY 行程计算 |
| `MAX_Z` | 打印机 max_z | 打印机 Z 轴限制 |
| `FULL_THICKNESS` | 瓦片类型 | Full=7.2mm, Lite=4.0mm, Heavy=13.8mm |

## 耗材估算

| 常量 | 值 | 说明 |
|------|-----|------|
| `FILAMENT_MAIN_PER_CELL` | 1.13g | 主耗材/格/层 |
| `FILAMENT_SUPPORT_PER_CELL` | 0.06g | 支撑耗材/格/层 |
| `PRINT_TIME_PER_CELL` | 3.1min | 打印时间/格/层 |

## 算法优先级

1. **最小化独特尺寸数量** - 减少需要打印的不同瓦片尺寸
2. **最小化瓦片总数** - 减少总打印次数
3. **最大化均衡度** - 使瓦片尺寸分布更均匀

## 搜索终止条件

找到 1 种独特尺寸方案时提前终止搜索。

## 分割规则

- 抽屉尺寸转换为网格数：宽度 / TILE_SIZE，高度 / TILE_SIZE
- 分割方案使用整数分割，确保瓦片边界对齐
- 分割数最大限制：20 块瓦片
